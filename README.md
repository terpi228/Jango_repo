# TRPEBSstore / SkyStore

Учебный проект Django — интернет-магазин с каталогом товаров и блогом.  
Реализованы полноценные CRUD-операции для продуктов и постов, валидация форм, стилизация, счётчик просмотров и уведомления по email.

---

## 📁 Структура проекта

- **catalog** — основное приложение с моделями `Product`, `Category`, `Contact`.
- **blog** — приложение для ведения блога с моделью `BlogPost`.
- Шаблоны наследуются от базового `base.html` (Bootstrap 5).

---

 🚀 Установка и запуск

1. **Клонируйте репозиторий**  
   ```bash
   git clone <your-repo-url>
   cd <project-folder>
   ```

2. **Создайте виртуальное окружение**  
   ```bash
   python -m venv venv
   source venv/bin/activate   # для Linux/Mac
   venv\Scripts\activate      # для Windows
   ```

3. **Установите зависимости**  
   ```bash
   pip install django pillow
   ```
   > Pillow необходим для работы с изображениями.

4. **Примените миграции**  
   ```bash
   python manage.py migrate
   ```

5. **Создайте суперпользователя (опционально)**  
   ```bash
   python manage.py createsuperuser
   ```

6. **Запустите сервер разработки**  
   ```bash
   python manage.py runserver
   ```

7. Откройте в браузере [http://127.0.0.1:8000](http://127.0.0.1:8000)

## 📦 Основной функционал

### Каталог (`catalog`)

- **Просмотр списка товаров** — на главной странице выводятся последние 5 товаров.
- **Детальная страница** — полная информация о товаре, просмотр изображения.
- **Создание товара** — форма с валидацией:
  - Запрещённые слова в названии и описании (`казино`, `криптовалюта`, `биржа` и др.) – проверка регистронезависимая.
  - Цена не может быть отрицательной (проверка через `clean_price`).
  - (Дополнительно) Валидация изображения: только JPEG/PNG, размер ≤ 5 МБ.
- **Редактирование и удаление** — доступны через кнопки на детальной странице.
- **Стилизация форм** — все поля получают класс `form-control` (Bootstrap) через `__init__` в форме.

### Блог (`blog`)

- **Список постов** — отображаются только опубликованные записи.
- **Детальный просмотр** — увеличивается счётчик просмотров.
- **Автоматическое уведомление** — при достижении 100 просмотров отправляется письмо на почту `mcrussai223@gmail.com`.
- **Полный CRUD** — создание, редактирование, удаление постов.
- **Превью изображений** — загрузка картинок для постов.

### Контакты

- Статичная страница с контактной информацией.
- Форма обратной связи (демонстрационная, отправка не реализована).

## 🛠 Используемые технологии

- **Django** (Python) — основной фреймворк.
- **Django Class-Based Views** — для CRUD операций.
- **Django Forms** — валидация, кастомные методы `clean_*`.
- **Bootstrap 5** — стилизация и адаптивная вёрстка.
- **Pillow** — работа с изображениями.
- **SQLite** — база данных (по умолчанию).

---

## 📝 Примечания

- Для отправки писем в блоге настройте `EMAIL_BACKEND` в `settings.py` (например, для консоли: `django.core.mail.backends.console.EmailBackend`).
- Запрещённые слова и максимальный размер файла легко настраиваются в `forms.py`.
- Все формы стилизованы единообразно — ошибки выводятся красным цветом (стиль задан в `base.html`).
