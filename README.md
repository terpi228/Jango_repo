# TRPEBSstore

Интернет-магазин плагинов и примеров кода с системой аутентификации пользователей.  
Реализован на Django с кастомной моделью пользователя, регистрацией, авторизацией по email, отправкой приветственного письма и разграничением доступа к управлению товарами.

---

## 🚀 Функциональные возможности

### Пользователи
- **Кастомная модель `User`** (наследуется от `AbstractUser`)
  - Поле для входа – **email** (`USERNAME_FIELD`)
  - Дополнительные поля: `phone`, `avatar`, `country`
- **Регистрация** с указанием email, пароля, телефона, аватара, страны
  - Подтверждение пароля
  - Отправка приветственного письма на email (в консоль для теста)
- **Авторизация** по email и паролю
- **Редактирование профиля** (изменение телефона, аватара, страны)
- **Выход** (с POST-запросом для безопасности)

### Товары (каталог)
- **Список товаров** – открыт для всех (без авторизации)
- **Создание, редактирование, удаление** – только для авторизованных пользователей
- **Валидация**:
  - Запрещённые слова в названии и описании
  - Цена не может быть отрицательной
  - Изображение: размер ≤ 5 МБ, форматы JPEG/PNG

### Административная панель
- Кастомизированный `UserAdmin` для удобного управления пользователями
- Стандартные админки для категорий, товаров, контактов

### Дополнительно
- Команда `csu` для быстрого создания суперпользователя
- Редирект с `/catalog/` на `/` (для удобства)
- Готов к деплою (настройки через `.env` для PostgreSQL)

## 📦 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone <url-репозитория>
cd Jango_repo
```

### 2. Создание виртуального окружения и установка зависимостей
```bash
python -m venv venv
source venv/bin/activate      # Linux/Mac
venv\Scripts\activate         # Windows
pip install -r requirements.txt
```

### 3. Настройка переменных окружения
Создайте файл `.env` в корне проекта со следующим содержимым (подставьте свои данные для PostgreSQL):
```env
POSTGRES_ENGINE=django.db.backends.postgresql
POSTGRES_NAME=your_db_name
POSTGRES_USER=your_db_user
POSTGRES_PASSWORD=your_password
POSTGRES_HOST=localhost
POSTGRES_PORT=5432
```
Для разработки можно использовать SQLite (измените настройки в `settings.py`).

### 4. Применение миграций
```bash
python manage.py makemigrations
python manage.py migrate
```

### 5. Создание суперпользователя (через кастомную команду)
```bash
python manage.py csu
```
или стандартный способ:
```bash
python manage.py createsuperuser
```

### 6. Запуск сервера разработки
```bash
python manage.py runserver
```
Сайт будет доступен по адресу: [http://127.0.0.1:8000/](http://127.0.0.1:8000/)

## ✨ Особенности реализации

- **Кастомный менеджер пользователей** – `UserManager`, упрощающий создание пользователей без поля `username`.
- **Формы** с автоматической стилизацией Bootstrap (миксин `StyleFormMixin`).
- **Защита представлений** – `LoginRequiredMixin` для классовых вьюх.
- **Выход** – только через POST (безопасность).
- **Письма** – для разработки используются `console.EmailBackend` (письма выводятся в терминал).
- **Переменные окружения** – все конфиденциальные данные вынесены в `.env`.
