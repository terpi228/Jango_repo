# TRPEBSstore

Веб-приложение на Django для управления каталогом товаров и блогом. Проект выполнен в рамках домашнего задания и демонстрирует использование классовых представлений (CBV), работу с PostgreSQL, а также полноценный CRUD для блога с дополнительной логикой.

---

## 📌 Возможности

- **Каталог товаров**  
  - Отображение последних 5 добавленных товаров на главной странице  
  - Детальная страница каждого товара  
  - Добавление нового товара через форму (CBV)  

- **Блог**  
  - Полный CRUD для блоговых записей (создание, чтение, обновление, удаление)  
  - Счётчик просмотров – увеличивается при каждом открытии статьи  
  - Фильтрация – в списке выводятся только опубликованные записи (`is_published=True`)  
  - Автоматическое перенаправление на детальную страницу после редактирования  
  - *Дополнительно:* отправка поздравления на почту, когда статья набирает 100 просмотров (в консольном режиме)

- **Контакты**  
  - Страница с контактной информацией  
  - Форма отправки сообщения (заглушка)

- **Административная панель** – удобное управление товарами, категориями, контактами и блогом

- **Адаптивный интерфейс** – стили Bootstrap 5

## 🚀 Запуск проекта

### 1. Клонирование репозитория

```bash
git clone <url-репозитория>
cd Jango_repo
```

### 2. Создание и активация виртуального окружения

```bash
python -m venv .venv
source .venv/bin/activate      # Linux/Mac
# или
.venv\Scripts\activate         # Windows
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка переменных окружения

Создайте файл `.env` в корне проекта со следующим содержимым (подставьте свои данные):

```env
POSTGRES_ENGINE=django.db.backends.postgresql
POSTGRES_NAME=имя_базы
POSTGRES_USER=пользователь
POSTGRES_PASSWORD=пароль
POSTGRES_HOST=localhost
POSTGRES_PORT=5432
```

Если вы используете SQLite, оставьте настройки по умолчанию.

### 5. Применение миграций

```bash
python manage.py makemigrations
python manage.py migrate
```

### 6. Создание суперпользователя

```bash
python manage.py createsuperuser
```

### 7. Запуск сервера

```bash
python manage.py runserver
```

Приложение будет доступно по адресу `http://127.0.0.1:8000/`.

## 📧 Отправка писем

По умолчанию настроен консольный бэкенд (`django.core.mail.backends.console.EmailBackend`) – все письма выводятся в терминал. Это удобно для тестирования.

Для реальной отправки измените в `settings.py`:

```python
EMAIL_BACKEND = 'django.core.mail.backends.smtp.EmailBackend'
EMAIL_HOST = 'smtp.yandex.ru'
EMAIL_PORT = 465
EMAIL_USE_SSL = True
EMAIL_HOST_USER = 'ваш_логин'
EMAIL_HOST_PASSWORD = 'ваш_пароль_приложения'
DEFAULT_FROM_EMAIL = EMAIL_HOST_USER
```
